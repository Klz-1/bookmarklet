# Personal Dashboard Extension + Onebox Integration (V2)

## Overview

Transform Browsing Tracker into a personal dashboard Chrome extension with:
- New Tab page replacement with quick links, stats, and widgets
- Google Auth for data persistence
- Local fuzzy search (Fuse.js)
- Optional opt-in sync to Onebox

## Phase 3: Local Fuzzy Search (Fuse.js)

### Why Fuse.js Instead of Transformers.js?
- **Size**: ~10KB vs 40MB model download
- **Complexity**: No offscreen document, no Web Workers
- **Speed**: Instant search, no model loading
- **Good enough**: Fuzzy matching handles typos, partial matches
- **Semantic search**: Delegated to Onebox when connected

### Files to Create
```
src/search/
├── SearchBar.tsx        # Search input component
├── SearchResults.tsx    # Results display
├── useSearch.ts         # Search hook
└── searchIndex.ts       # Fuse.js index management
```

### Dependencies
```json
{
  "dependencies": {
    "fuse.js": "^7.0.0"  // ~10KB gzipped
  }
}
```

### Search Index Setup
```typescript
// src/search/searchIndex.ts
import Fuse from 'fuse.js'

const fuseOptions = {
  keys: [
    { name: 'title', weight: 0.4 },
    { name: 'url', weight: 0.2 },
    { name: 'domain', weight: 0.2 },
    { name: 'content', weight: 0.2 }  // For Twitter bookmarks
  ],
  threshold: 0.4,        // 0 = exact, 1 = match anything
  includeScore: true,
  minMatchCharLength: 2
}

export function createSearchIndex(items: SearchableItem[]) {
  return new Fuse(items, fuseOptions)
}
```

### Search Flow
1. User types query in search bar
2. Debounce input (300ms)
3. Search across visits + Twitter bookmarks with Fuse.js
4. Display ranked results instantly

### Hybrid Approach (When Connected to Onebox)
```typescript
async function search(query: string) {
  // Always do local fuzzy search
  const localResults = fuseIndex.search(query)

  // If connected to Onebox, also do semantic search
  const auth = await getAuthState()
  if (auth?.token && syncConfig.enabled) {
    const semanticResults = await oneSpaceSearch(query, auth.token)
    return mergeResults(localResults, semanticResults)
  }

  return localResults
}
```
